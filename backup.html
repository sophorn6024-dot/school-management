បម្រុងទុកទិន្នន័យ (Backup)

⛔ មុខងារនេះសម្រាប់តែ Admin ប៉ុណ្ណោះ។
ជ្រើសតារាងដែលចង់បម្រុងទុក
របៀបប្រើ និងការណែនាំ
  1. ទាញយក Excel សម្រាប់មើល និងបោះពុម្ព (មួយសន្លឹកក្នុងមួយតារាង)។
  2. ទាញយក JSON សម្រាប់ស្តារទិន្នន័យពេញលេញ (រួមទាំងរូបថត)។
  3. រក្សាទុកឯកសារ ២ កន្លែង ឧ. កុំព្យូទ័រ និង Google Drive។
  4. គួរបម្រុងទុក ម្តងរាល់ចុងខែ និង ចុងឆ្នាំសិក្សា ហើយមុនពេលលុប ឬកែទិន្នន័យច្រើន។
  5. ឯកសារមានព័ត៌មានសិស្ស សូមរក្សាទុកដោយសុវត្ថិភាព កុំចែកចាយសាធារណៈ។ ពាក្យសម្ងាត់មិនត្រូវបានបម្រុងទុកទេ។
ℹ️ Supabase Free មិនមាន backup ស្វ័យប្រវត្តិ ហើយគម្រោងត្រូវផ្អាកបើមិនប្រើ ១ សប្តាហ៍។ ទិន្នន័យមិនបាត់ទេ ប៉ុន្តែត្រូវចុច Restore ក្នុង Dashboard។
